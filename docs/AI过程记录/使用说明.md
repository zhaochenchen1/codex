# 使用说明

## 快速开始
1. **环境检查**: 确保 `~/.zshrc` 中已配置 `IWENCAI_API_KEY`。
2. **技能安装**: 使用 `iwencai-skillhub-cli install <skill-name>`。
3. **运行查询**:
   ```bash
   python3 code/skills/<skill-name>/scripts/cli.py --query "你的问句"
   ```

## 注意事项
- 所有的查询数据均来源于**同花顺问财**。
- 如果查询无结果，建议简化问句或前往问财官网手动查询。
- 本地技能存储在 `code/skills` 目录下。

- **位置**: `code/fill/market_perception.py`
- **底层支撑**: `code/fill/wencai_api.py` (标准化 OpenAPI 封装)
- **核心功能**: 提供全市场的深度扫描，包括：

    ```bash
    python3 code/fill/market_perception.py
    ```
