# 尝试失败的记录

记录在开发和配置过程中遇到的问题及解决方案。

## [2026-05-09 16:55] 环境安装阶段
### 1. Iwencai SkillHub 官方安装脚本失败
- **现象**: 运行 `download_and_install.sh` 报错 `aime-install.sh not found`。
- **原因**: 压缩包内的脚本名称为 `iwencai-install.sh` 而非脚本中预期的 `aime-install.sh`。
- **解决**: 手动解压并执行了 `iwencai-install.sh`。

## [2026-05-13 14:30] 历史全量回溯压测
### 1. 历史指数数据回溯全线失效 (Direct 模式)
- **现象**: 强制使用 `pywencai` 回溯 5月4日-7日数据，报告中 OHLC 全为 `--` 或 `0`。
- **原因**: 问财直连查询历史日期（如 `000001.SH 20260506收盘价`）返回的是相关新闻或成分股列表，而非结构化行情行，解析器无法捕获字段。
- **解决**: 引入 **AkShare (Sina 渠道)** 作为三级降级兜底。

### 2. 总控脚本在 API 401 时崩溃
- **现象**: 当 SkillHub 额度耗尽抛出 `Exception` 时，总控脚本直接终止，未能切换至 Direct 模式。
- **原因**: `run_sentiment_module` 内部未对底层 API 错误进行颗粒度捕获。
- **解决**: 在总控调度层增加 `try...except` 保护。
### 1. SkillHub API 额度耗尽 (401 Error)
- **现象**: 执行大批量查询（股价/市值分布）时报错 `API Error 401: 您今天的次数已用完`。
- **原因**: SkillHub 免费版 API 每日调用频率有硬上限。
- **解决**: 实现了 `market_perception_direct.py`，切换至 `pywencai` 直连库，绕过 Key 额度限制。

### 3. JSON 缓存序列化与解析失败
- **现象**: 脚本运行报错 `TypeError: Object of type DataFrame is not JSON serializable` 或 `Expecting value: line 1 column 1`。
- **原因**: 
    1. 直接将 Pandas DataFrame 存入字典并尝试 `json.dump` 会失败。
    2. 当 API 返回 None 或空字典时，缓存被写入了非标准内容或空内容，导致下次加载时解析崩溃。
- **解决**: 
    1. 在 `_save_cache` 中增加深度转换逻辑，确保所有 DataFrame 均通过 `to_dict(orient='records')` 转换为列表。
    2. 在 `_load_cache` 中增加空值和异常校验。

### 5. 历史指数元数据获取全为 0
- **现象**: 运行 `资金情绪获取.py` 后，生成的 JSON 和 MD 文件中所有数值均为 0 或 0.00%。
- **原因**: `pywencai` 的直连模式（Direct Mode）在处理带有具体日期的指数指标查询时（如 `000001.SH 20260511收盘价`），常因语义解析偏差返回非表格类的字典（如仅含 `title_content`），导致 `_safe_fetch` 无法提取有效数据。
- **解决**: 
    1. 切换回 **SkillHub API 模式** (`v1/query2data`)，该模式对历史日期的结构化查询支持更稳健。
    2. 优化问句为：`{code}，{date}收盘价，昨日收盘价...`。
    3. 在代码中增加对 `dict` 和 `DataFrame` 的兼容处理逻辑。
### 3. 数据解析报 KeyError: 'pct_chg'
- **现象**: `LongtouMonitor` 执行时抛出 `KeyError: 'pct_chg'`。
- **原因**: 问财 API 在处理“概念指数”相关查询时，返回的列名包含日期后缀（如 `涨跌幅:前复权[20260511]`）或者直接重定向到了个股结果页面，导致固定的字段映射失效。
- **解决**: 
    1. 引入了模糊列名匹配逻辑。
    2. 最终采用了“个股数据聚合”策略：先抓取包含所属概念的所有个股，再在代码中进行 `groupby` 聚合，彻底解决了指数数据不稳定的问题。
