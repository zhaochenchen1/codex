# 可用 API 列表

本项目的技能主要通过同花顺问财 OpenAPI 获取数据。

## 核心接口
- **URL**: `https://openapi.iwencai.com/v1/query2data`
- **Method**: `POST`
- **Auth**: `Bearer <IWENCAI_API_KEY>`

## 主要查询能力
1. **股东股本查询** (hithink-management-query)
2. **行情数据查询** (hithink-market-query)
3. **指数数据查询** (hithink-zhishu-query)
4. **市场情绪偏离分析** (市场情绪偏离分析)

## [2026-05-11 14:20] 策略逻辑 API 补充 (来自 his/ 目录)
### 1. 问财增强查询 (pywencai)
- **底层引擎**: 问财 i问财 (iwencai.com)
- **常用 Query 模式**:
    - `连续涨停天数>0, 涨跌幅, 换手率, 成交额, 股票简称, 行业` (龙头股脱水)
    - `{日期}涨停，连续涨停天数>=2，非ST，非退市，今日最低价，最新价，{日期}的5日均线` (Sniper 战法)
    - `{日期}涨停，非ST，非新三板，所属概念，{日期}首次涨停时间` (热点镜像对比)
- **聚合策略 (新)**:
    - Query: `非ST，非新三板，所属概念，涨跌幅，资金流向`
    - 用途: 当直接查询“概念指数”返回数据不稳定时，通过个股数据在 Python 层进行 `groupby` 聚合，得出板块平均涨幅和总资金流入。
- **异动解析 (新)**:
    - Query: `{板块名}今日异动解析`
    - 用途: 自动获取板块上涨的底层逻辑（利好政策、行业动态等）。
- **备注**: 动态字段名处理（如 `涨停家数[20260508]`）是解析重点。

### 2. AkShare 金融数据接口
- **接口名称**: `ak.tool_trade_date_hist_sina()`
- **功能**: 获取新浪财经 A 股交易日历历史。
- **用途**: 判定当前是否为交易日，计算 T-1, T-2 等历史交易日期。

### 4. 市场感知分析查询 (market_perception.py)
- **Endpoint**: `https://openapi.iwencai.com/v1/query2data`
- **新增 Query 模式**:
    - **历史情绪强校验**: `{code}，{target_day}收盘价，昨日收盘价，{target_day}成交额，昨日成交额...` (用于历史数据的精确对齐)
- **解析逻辑**:
    - **板块排名**: `今日涨幅前二十的板块，板块涨跌幅`, `今日跌幅前二十的板块，板块涨跌幅`
    - **指数历史位置**: `上证指数，深证成指，创业板指，科创50近一年的最高点`
    - **股价区间分布**: `非ST，股价在{low}到{high}元之间，今日上涨家数，今日下跌家数`
    - **市值区间分布**: `总市值在{low}到{high}亿之间，今日上涨股票数量，今日下跌股票数量`
- **解析逻辑**:
    - 使用 `WencaiAPI` 统一封装请求头（X-Claw-*）。
    - 动态解析带日期的字段名（如 `收盘价[20260512]`）。
    - 实现了板块按题材自动归类（半导体、AI、新能源等）。
### 6. AkShare 指数历史数据 (ak.stock_zh_index_daily)
- **获取渠道**: `ak.stock_zh_index_daily(symbol=...)`
- **主要参数**: 
    - `sh000001`: 上证指数
    - `sz399001`: 深证成指
    - `sz399006`: 创业板指
    - `sh000688`: 科创50
- **字段能力**: 返回标准的 `open, high, low, close, volume` 时间序列，极其稳定，无额度限制。
- **用途**: 作为“资金与情绪”模块在历史回溯阶段的最终兜底手段，确保 OHLC 指标 100% 填充。
