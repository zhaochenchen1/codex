## 2. 数据获取与准入方案
该模块属于数据链下游，必须在确保上游数据质量的前提下运行。

### 2.1 准入红线 (Integrity Gating)
- **依赖检查**: 必须先读取 `funds_sentiment` 模块。
- **熔断机制**: 若“资金情绪”模块的 `integrity` 不为 `complete`（即四个指数数据不全或核心点位为0），则**强制跳过**本模块计算。
- **输出处理**: 熔断时，MD 报告需明确显示 `> [前置资金情绪数据不齐，评分挂起]`。

### 2.2 维度计算与对齐
- **一年内最高点**: 必须通过具体代码和 target_date 进行强对齐获取。
- **位置计算**: `(当前点数 / 一年内最高点) * 100%`，结果强制保留两位小数并带 `%`。

## 3. 数据展示规范
- **禁止原始 Key 泄露**: 表格中禁止出现 `sh`, `sz`, `pct`, `vol_growth` 等内部 Key。
- **统一列名映射**:
    - `涨跌幅` (取代 pct)
    - `成交额增长率` (取代 vol_growth)
    - `一年内位置` (取代 position)
- **排名展示**: 必须按 `final_score` 从高到低降序排列。

**注意事项**:
- **位置计算**: 必须确保 `current_close` 和 `year_high` 为同日期口径。
- **排名平分处理**: 若数值相同，则取相同排名（如两个第一名）。
- **感悟生成**: 需结合最高分指数与最低分指数的差异进行描述。
