## 2. 动态获取渠道方案
根据运行时间点，自动切换获取渠道与缓存策略。

| 时间窗口 | 定义 | 获取渠道 | 缓存策略 |
| :--- | :--- | :--- | :--- |
| **盘中时间** | 交易日 09:15 - 15:05 | **pywencai Direct** | **强制实时获取**，不读取本地缓存，结果标记为 `realtime` |
| **盘后时间** | 交易日 15:05 之后 | **SkillHub API** | **缓存优先**：若 JSON 中已存在 `source: skillhub` 的数据，则直接读取；否则获取并写入，标记为 `final` |

**问财 Query 模板 (复合请求)**:
`"20260512股价在0-10元且非ST的上涨家数，下跌家数；股价在10-100元且非ST的上涨家数..."` (以此类推拼接所有区间)

## 3. 数据展示规范 (Formatting Standards)
为提升报告的专业性并防止内部代码泄露，必须执行以下展示标准：

### 3.1 业务标签映射 (ID Translation)
渲染 MD 时，禁止出现 JSON Key (b1, st 等)，必须按以下映射表进行翻译：

| JSON Key | 业务标签 (MD 展示) |
| :--- | :--- |
| `b1` | (0, 10] 元 |
| `b2` | (10, 100] 元 |
| `b3` | (100, 300] 元 |
| `b4` | (300, 500] 元 |
| `b5` | (500, 2000] 元 |
| `st` | ST 股全体 |

### 3.2 标准五列制 (Strict 5-Column Table)
股价偏好表格必须包含且仅包含以下 5 列，顺序不得调整：
1. **[股价区间]**
2. **[上涨家数]**
3. **[下跌家数]**
4. **[上涨比例]** (计算公式：up / total)
5. **[下跌比例]** (计算公式：100% - 上涨比例)

### 3.3 补全规则
- 所有的比例数值必须保留两位小数并带 `%`（如 `45.00%`）。
- 若某区间数据为 0，则显示为 `0` 和 `0.00%`，不得显示为 `None`。
