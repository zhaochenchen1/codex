## 2. 数据获取与架构方案
该模块采用 **“SkillHub 优先，直连次之，AkShare 兜底”** 的三级降级架构。

### 2.1 类定义规范
1.  **`SentimentSensorSkillHub`**: 首选渠道，仅使用 OpenAPI。
2.  **`SentimentSensorDirect`**: 
    - 仅使用 `pywencai` 爬虫。
    - **AkShare 兜底逻辑**: 若爬虫无法返回结构化指数行（常见于历史追溯），必须自动调用 `akshare` 接口（如 `stock_zh_index_daily`）获取当日 `open, high, low, close, volume` 及上涨/下跌家数。

| 优先级 | 渠道 | 触发条件 | 目标数据 |
| :--- | :--- | :--- | :--- |
| **1** | SkillHub API | 默认发起 | 12项完整指标 |
| **2** | pywencai Direct | API 限额或失败 | 基础指标 (补位) |
| **3** | **AkShare** | 历史追溯且 Direct 失效 | OHLC、成交额、家数 |

## 3. 数据质量管理 (Data Governance)
### 3.1 完整性标记
- **`complete`**: 四大指数 12 项指标非零。
- **`partial`**: 部分指标为 0，MD 中显示 `--`。

## 4. 数据存储标准 (JSON Schema)
统一采用以 **日期字符串** 为最顶层 Key，便于多日数据聚合。

```json
{
  "2026-05-11": {
    "funds_sentiment": {
      "metadata": {
        "status": "final",
        "integrity": "complete",
        "source": "skillhub",
        "fetch_time": "..."
      },
      "data": {
        "sh": { "open_pct": "+0.10%", ... },
        "sz": { ... }
      },
      "summary": "..."
    }
  }
}
```

**注意事项**:
- 所有百分比字段在 JSON 中存储带 `%` 的字符串，方便前端直接渲染。
- 金额字段（volume, vol_chg）统一转换为“亿”单位，保留两位小数。
- `summary` 字段由 AI 或逻辑脚本根据表格数据特征自动生成。
